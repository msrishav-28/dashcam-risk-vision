# What this repo is not

- Not ADAS, AEB, or a driver-monitoring product.
- Not a Tesla / CARLA Autopilot clone.
- Not occupancy / BEV / nuScenes full stack.
- Not a pothole detector.
- Not combat-vehicle vision.
- Numbers in the README must come from `experiments/`. Until that folder has a run, there are **no** accuracy claims.
